# Mission: SWE Foundations — Stage 0 (Fluency & Tools)

## Why

Make the base reflexive so nothing later fights you — "tooling becomes reflex, not friction." The six Primary Colors roadmap structures the whole SWE journey; this mission is its Stage 0 (Color 6: Process). Full roadmap: `Knowledge Wiki/wiki/SWE Primary Colors & Roadmap.md`.

## Success looks like

- A runnable C program with a reproducible build (the monitor course's first success criterion).
- Shell, git, and debugging fluency from MIT Missing Semester.
- Tested code: a testable seam, fixtures, boundary cases, Arrange–Act–Assert, red–green–refactor, smoke tests.
- A working Linux system monitor in C (the Stage-0 capstone), built one reasoning step at a time.
- 2–3 small CLI tools (design TBD once the monitor course is done), each with git + tests.

## Constraints

- Manual triggers; moderate pace; step-by-step + real-world analogies (soccer).
- Automatic interleaving at the practice/retrieval level (one color at a time for first introductions; mix in capstones and quizzes).
- Guided Socratic questioning (never pure Socratic — resolve confusion immediately with an analogy or smaller step).
- Push toward higher-order thinking (Bloom), phase-mapped; lessons are short and completable.
- A lesson advances only after demonstrating the lesson's skill (retrieval check + Feynman explain-back).
- Local-first repo; source of truth is this GitHub repo.

## Out of scope

- Stages 1–6 of the roadmap (Computation, Systems, Abstraction, State, Interaction, White-Light capstones) — for later missions.
- AI Engineering / Data Science roadmap (paused).
- Wisdom/community sourcing (reserved for a later round; see RESOURCES.md).
- Scripture Memory (separate skill, untouched).
