## Knowledge

- [MIT Missing Semester (2026)](https://missing.csail.mit.edu/2026/) — shell, git, debugging, editors. Primary curriculum source for Strand B.
- [GNU Make Manual](https://www.gnu.org/software/make/manual/) — targets, prerequisites, recipes. Primary reading for A1 [9]. Use for: any Makefile claim.
- [GCC overall options](https://gcc.gnu.org/onlinedocs/gcc/) — compiler flags, compile stages. Use for: A1 + build explanations.
- [Bill Wake — Arrange, Act, Assert](https://xp123.com/articles/3a-arrange-act-assert/) — the 3A pattern vocabulary. Primary reading for A2 [8].
- [Acutest README and examples](https://github.com/mity/acutest) — the test runner. Use for: A3, all test-authoring claims.
- [proc_meminfo(5)](https://man7.org/linux/man-pages/man5/proc_meminfo.5.html) — primary reading for A4 [6]. Use for: MemTotal/MemAvailable semantics.
- [/proc/stat CPU formulas](https://man7.org/linux/man-pages/man5/proc.5.html) — USER_HZ counters, busy/idle math. Use for: A5 [5].
- [proc_pid(5) / readdir(3)](https://man7.org/linux/man-pages/man5/proc_pid.5.html) — numeric PID directories, comm vs stat. Use for: A6 [4].
- [kilo editor (snaptoken)](https://viewsourcecode.org/snaptoken/kilo/) — termios raw mode, signals, redraw. Use for: A7 [3].
- [ANSI escape code reference](https://en.wikipedia.org/wiki/ANSI_escape_code) — cursor/erase sequences. Use for: A7.
- [terminal state & termios(3)](https://man7.org/linux/man-pages/man3/termios.3.html) — canonical vs raw input. Use for: A7.
